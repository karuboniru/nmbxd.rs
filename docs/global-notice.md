# X岛启动公告

启动时在独立后台任务中请求 `https://nmb.ovear.info/nmb-notice.json`，不携带饼干，不阻塞板块和帖子请求。公开 [API 文档](https://github.com/TransparentLC/xdcmd/wiki/自己整理的-X-岛匿名版-API-文档#查看匿名版公告) 定义了 `content`（HTML 正文）、`date`（数值发布时间标识）、`enable`（是否启用）三个字段。2026-10-26 已核验该接口返回此格式。

有效且未标记已读的公告自动弹窗，上部正文可滚动、选择复制和打开链接；下部固定显示关闭按钮和“已读，下次不再显示这条公告”复选框。直接关闭或按 Escape 不标记已读，下次启动仍会显示。勾选立即保存，取消勾选立即撤销；保存失败时在弹窗中提示，并保留原勾选状态。

已读记录独立保存到应用配置目录中的 `global-notice.json`，使用发布时间与原始正文的 SHA-256 摘要识别当前公告。新发布时间或正文变更都会再次弹窗。未启用、正文为空、请求失败或格式无效时不弹窗，也不清除已有记录。请求失败只记入诊断输出，下次启动重新检查。
